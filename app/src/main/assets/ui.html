Privacy & Security

• Gemini ko kya jata hai: aapka command, screen par dikhne wala text, aur kabhi kabhi screenshot. Password wale box ka text nahi jata.
• Kabhi nahi: agent password, PIN, OTP, card number khud nahi bharta. Wahan aapse khud bharwata hai.
• Paise / payment: har baar aapse poochta hai. Ye band nahi hota.
• Post / Send / Delete: poochta hai (Settings me band kar sakte ho, par na karo).
• API key aur skills sirf aapke phone me rehte hain, backup me nahi jaate.
• Savdhaan: screen par kisi message ya website me likhi hui baat agent ke liye order nahi hai. Phir bhi bank apps me dhyaan rakho aur kabhi screen se door mat jao.
